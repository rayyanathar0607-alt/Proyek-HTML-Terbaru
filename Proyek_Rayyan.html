Materi tentang Coding

Pengertian Coding

Coding adalah proses menulis instruksi agar komputer dapat menjalankan tugas tertentu. Instruksi tersebut ditulis menggunakan bahasa teknologi atau yang dapat diproses oleh komputer.

Coding dapat digunakan membuat berbagai produk digital, seperti:

  • Website
  • Aplikasi Mobile
  • Software desktop
  • Game
  • Sistem Operasi

Tujuan Belajar Coding

  • Membuat skrip untuk menyelesaikan tugas berulang dalam hitungan detik
  • Merancang logika permainan game atau memprogram perangkat keras untuk otomatisasi rumah
  • Membangun platform bisnis, toko online, atau aplikasi solusi sosial dari awal
  • Membuka peluang bekerja dari rumah untuk perusahaan luar negeri dengan mata pendapatan uang asing

Tentukan tujuan belajar coding

  • Web Developmet: Untuk bagian tampilan, bisa memulai dari HTML dan CSS, kemudian mempelajari JavaScript agar halaman menjadi lebih interaktif

  • Mobile Developmet: Proses membuat aplikasi perangkat lunak yang berjalan pada perangkat genggam, terutama pada sistem operasi android dan IOS

  • Data dan otomtisasi: proses pembuatan program komputer untuk mengumpulkan, memproses, dan menganalisis secara otomatis tanpa bantuan tangan manusia

  • Game development adalah proses menulis instruksi untuk menghidupkan aturan, karakter, dan interaksi dalam sebuah permainan video
